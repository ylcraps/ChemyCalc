# ChemyCalc

ChemyCalc — это учебный проект офлайн-приложения по химии для школьников 8–11 классов.

## Что уже сделано в этом первом этапе

1. Создан каркас Android-приложения на Kotlin + Jetpack Compose.
2. Добавлена базовая структура проекта для Android Studio.
3. Реализован стартовый экран с поиском по темам.
4. Подготовлена база тем по химии: периодический закон, строение атома, реакции, гидролиз, галогены, изомеры и другие разделы.
5. Создана схема последующих этапов для расширения до полноценного справочника и решения задач.

## Структура проекта

- `app/` — Android app module
- `app/src/main/java/com/chemycalc/app/` — основная логика интерфейса
- `app/src/main/java/com/chemycalc/app/data/` — учебные данные
- `app/src/main/java/com/chemycalc/app/ui/theme/` — тема и стили Compose
